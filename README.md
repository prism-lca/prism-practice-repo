## Working locally on a Mac

You don't need the dev container to work on your own Mac. Clone the repo, then
run this once from the repo folder:

```
./setup_local_tools.sh
```

It installs whatever is missing (Node, gh, Python, Claude Code, Codex,
opencode, and the chart and slide tools), then sets up this repo's MCP servers,
skills and agents. If it asks you to install the Xcode command line tools or
Homebrew first, do that and run it again. Run `./setup_local_tools.sh --check`
to see what's installed without changing anything.

In a codespace none of this is needed: everything is already set up.
