# Diana's Sale Price Calculator

A finished example of the test-first practice project, built for issue #59
and merged in pull request #60.

- `index.html`: the calculator page
- `sale.js`: the calculation
- `sale.test.js`: the tests, one per rule

The plan, including the extra rule Diana added (no 100% discounts), is in
[plans/issue-59-plan.md](../../plans/issue-59-plan.md).

Run the tests with `node --test test-driven-development-example/diana/*.test.js`.

To try the project yourself, use the template:
https://github.com/prism-lca/tdd-sale-calculator
