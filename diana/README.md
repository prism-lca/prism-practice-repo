# Diana's Sale Price Calculator

This folder is for Diana's copy of the practice project. Build it here, test
first, by following [docs/sale-price-calculator.md](../docs/sale-price-calculator.md).

When it's done, this folder will hold:

- `index.html`: the calculator page
- `sale.js`: the calculation
- `sale.test.js`: the tests, one per rule

Run the tests with `node --test diana/*.test.js`.
