# Practice project: a Sale Price Calculator, built test first

This practice project has moved to its own template repo, so anyone can make
their own copy and try it:

**https://github.com/prism-lca/tdd-sale-calculator**

`tdd-sale-calculator-<your-name>`. The README there walks you through the rest.
