# Calvin

This page was made as a practice run of the branch, plan and fix workflow, for
issue #32.

The workflow steps are:

1. **Branch:** work on its own branch, `issue-32-branch`.
2. **Plan:** write and approve a plan before changing anything else.
3. **Fix:** make the change in small commits.
4. **Record the commits:** list the commits and files changed in the plan.
5. **Pull request:** open a pull request into `main`.
6. **Review:** reviewers ask for changes, then merge.

See [AGENTS.md](../AGENTS.md) for the full description.
